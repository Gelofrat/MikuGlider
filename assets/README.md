# Runtime assets

The root assets belong to Hatsune Miku v1. The `v2` and `v3` folders contain the other variants. Meshes, hair animations, model definitions and textures are embedded in the plugin by `MikuGlider.csproj`.

Model authoring files and local test fixtures are kept outside the published repository. The files here are sufficient to build the plugin with an installed copy of Mycopunk and BepInEx.

Keep [ATTRIBUTION.md](../ATTRIBUTION.md) with redistributed model derivatives. Game assemblies and decompiled sources are not distributed.
